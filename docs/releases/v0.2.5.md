CAVY 0.2.5: a better AI assistant chat.

- **Replies are formatted.** The assistant's Markdown is rendered: headings, bold and italic, numbered and nested lists, tables, quotes and links (links open in your browser). Code sits in a dark block with the language and a Copy button.
- **You and the assistant look different.** Your messages are dark bubbles on the right; the assistant's replies have an icon and a name and use the full width. Three animated dots show while it is thinking.
- **No jump to the bottom.** After an answer arrives the chat scrolls to where the answer starts.
- The chat column is wider, and lab problems and instructions use the same renderer (tables, code blocks with Copy).
