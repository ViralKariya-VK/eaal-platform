CAVY 0.2.2: teaching assignments, lab start times and a tidier "My class".

- **Teaching (admin panel).** Subjects per programme and semester (the MSc Data Science ones are built in), and an administrator allots a subject, a division and a batch (or both batches) to a professor. Their class fills with the matching students now, and with each new set of students as they reach that semester. A new Academic year card shows who sits in which year.
- **My class (professor).** A search box and Course / Division / Batch filters (including both batches) over a compact scrolling table. Adding groups or single students moved into folded sections.
- **Labs.** An optional start time; "any batch" labs can be made once per batch with their own times; Duplicate copies a lab to another division, batch or time. Students see only labs from professors who teach them.
- **Lab stages.** Students no longer see the problem, description or difficulty until the assessment stage starts; they see the title and topic. Descriptions are for the problem only.
