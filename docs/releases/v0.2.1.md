CAVY 0.2.1: a better Users page, and email that works from the installed app.

- **Users page (admin panel).** Search by name, SAP ID, email or roll number; filter by programme, batch of, division, batch and status; a table that scrolls inside the page with a fixed header and one-line rows; the less common actions (reset password, disable, delete) sit in a "More" menu. Filters and the search survive the page refreshing itself.
- **Email sending fixed.** Sending a test email, first-login passwords and reset codes failed with "certificate verify failed: unable to get local issuer certificate" when the app did not know which certificate authorities to trust. It now uses the certificate list that ships with the app.
