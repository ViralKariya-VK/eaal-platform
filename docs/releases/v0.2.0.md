CAVY 0.2.0: updates, matching versions and a polish pass.

- **Update notice.** The app now tells you when a newer CAVY is out and links to the download. It never installs anything by itself, and never interrupts a lab.
- **One version per class.** A server and the apps that connect to it must run exactly the same version; a different one is refused with a message saying which side to update. Hosting a server warns first when a newer version exists.
- **Screen-by-screen QA fixes.** The admin "Change teachers" button works again; labs and follow-ups reject impossible times and blank titles; double clicks no longer create duplicates; Reset asks before wiping code; dialogs work with the keyboard; clearer contrast, focus and layouts on small windows.
